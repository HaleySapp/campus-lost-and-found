# Haley - Found Item Prototype

## Assignment
Critical Feature: Community user posts a found item.

Estimated Story Points: 5

## Files / Areas to Complete
- FoundItemReport.java
- Found-item portion of ItemReportController.java
- Found-item portion of ItemReportService.java
- Found-item portion of ItemReportRepository.java
- Found Item user interface

## What It Needs To Do
- Allow the user to report a found item.
- Collect item/category, date found, location, color/brand, and description/distinguishing characteristics.
- Require a photo for a found item.
- Required fields must be completed.
- Successful submission should be marked pending security review.

## Deliverables
- Revised user story and acceptance criteria
- Low-fidelity Found Item wireframe
- Small working found-item implementation
- Screenshot of working feature
