# Tyler - Lost Item Prototype

## Assignment
Critical Feature: Community user posts a lost item.

Estimated Story Points: 5

## Files / Areas to Complete
- LostItemReport.java
- Lost-item portion of ItemReportController.java
- Lost-item portion of ItemReportService.java
- Lost-item portion of ItemReportRepository.java
- Lost Item user interface

## What It Needs To Do
- Allow the user to report a lost item.
- Collect item/category, date lost, location, color/brand, and description/distinguishing characteristics.
- Photo is optional for a lost item.
- Required fields must be completed.
- Successful submission should be marked pending security review.

## Deliverables
- Revised user story and acceptance criteria
- Low-fidelity Lost Item wireframe
- Small working lost-item implementation
- Screenshot of working feature
