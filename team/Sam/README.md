# Sam - Login Prototype

## Assignment
Critical Feature: All users can log in.

Estimated Story Points: 3

## Files / Areas to Complete
- AuthController.java
- AuthenticationService.java
- UserRepository.java
- Login user interface

## What It Needs To Do
- Allow the user to enter mock campus credentials.
- Valid credentials allow access.
- Invalid credentials display an error.
- Do not connect to UNCW's real authentication system.

## Deliverables
- Revised user story and acceptance criteria
- Low-fidelity login wireframe
- Small working login implementation
- Screenshot of the working login feature
